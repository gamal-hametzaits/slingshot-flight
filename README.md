# מעוף הרוגטקה

משחק אנדרואיד בעברית: מושכים ציפור אחורה, בוחרים כוח וכיוון, עפים דרך מסלולי מכשולים וטורבו אל השער. גרסה 1.0: חמישה מסלולים, כוכבים, מגן ואפשרות לשנות כוח. אין פרסומות או רכישות.

- המשחק והנתונים מוגשים מ-Cloudflare Worker ב-`worker.js`.
- `GET /health` בודק גרסה וזמינות; `GET /api/levels` מגיש את המסלולים לאפליקציה.
- `android/` מכיל מעטפת WebView שטוענת את המשחק מהשרת. המשחק דורש אינטרנט; התקדמות ושדרוגים נשמרים מקומית בטלפון.
- `build-apk.sh` בונה APK חתום ב-GitHub Actions; קובץ החתימה והסיסמה מוחזקים ב-GitHub Secrets, לא בריפו.

## מגבלות
אין משחק מרובה משתתפים או טבלת שיאים אונליין בגרסה הזו; השרת מגיש את המשחק והמסלולים, ולא מנהל חשבונות. Cloudflare Workers Free מאפשר עד 100,000 בקשות ביממה; אם המכסה נגמרת האפליקציה לא תטען עד האיפוס (ללא חיוב). לא נבדק בטלפון פיזי.
